# 수서 아로마 체험 랜딩페이지

인스타그램 숏폼 댓글 → 자동 DM → 랜딩페이지 → 카카오톡 상담 → 수서센터 방문으로 이어지는 **40분 1:1 아로마 체험 신청 페이지**.

- 운영: 이랑코치 (@erang_coach) / Team ERANG · 도테라트리플센터
- 목적: 체험 신청 1개 (제품·비즈니스 안내는 현장에서 진행)
- 형태: 모바일 우선 단일 HTML 페이지 (인스타 인앱 브라우저 기준)

---

## 1. 전체 퍼널

```
숏폼 영상 → 댓글 → 자동 DM(버튼) → 활용법 이미지 + 랜딩 링크
        → 체험 신청 → 카카오톡 일정 확정 → 수서센터 40분 체험
```

| 단계 | 내용 | 목적 |
|---|---|---|
| 1 | 댓글 직후 자동 DM (버튼 포함) | 발송 제한 회피, 반응 유도 |
| 2 | 버튼 클릭 → 활용법 이미지 1장 + 랜딩 링크 | 가치 제공 + 신청 유도 |
| 3 | 랜딩에서 신청 메시지 생성 → 카톡 전송 | 신청 접수 |
| 4 | 카톡으로 일정 확정 | 방문 전환 |

### DM 문구 (복붙용)

**1단계 (댓글 직후 자동)**

```
댓글 감사해요 😊
[오일명] 활용법 한 장으로 정리해 뒀어요.
아래 버튼 누르면 바로 보내드릴게요 👇
[활용법 받기]
```

**2단계 (버튼 클릭 후)**

```

저장해 두고 필요할 때 꺼내 보세요 🌿
향은 직접 맡아보는 게 제일 정확해요.
수서센터에서 무료 체험 가능해요 👇
[랜딩 링크]
```

## 2. 페이지 구성

위에서 아래 순서.

1. **히어로**: 센터 사진 배경 + 고민 중심 헤드라인 + 요약(무료 · 40분 · 1~2인 · 10ml 롤온) + 신청 버튼
2. **이런 분께 추천**: 체크리스트 4개
3. **40분 진행 순서**: 고민 체크 5분 → 오일 6종 시향 15분 → 핸드 아로마 터치 10분 → 롤온 만들기 10분
4. **사진 2장**: 시향 오일 / 직접 만드는 롤온
5. **가져가는 것**: 롤온 10ml 1병 + 시간대별 사용법 카드
6. **금요일 그룹 클래스**: Healing Friday 소개 (1:1이 부담스러운 경우의 대안)
7. **코치 소개**: 정종범 · 이랑코치 · 웰니스 리더
8. **미리 약속드려요**: 권유 없음 / 요청 시에만 안내 / 하루 안에 답장 + 도테라 사용 공개
9. **체험 신청 폼**: 이름 · 전화번호 · 고민 · 희망 일정
10. **오시는 길**: 주소 복사, 네이버 지도 링크
11. **FAQ**: 5개
12. **푸터**: 트리플그룹 로고 / 하단 고정 신청 버튼

## 3. 신청 방식

서버나 DB 없이 동작. 신청 내용을 **메시지로 자동 생성**해서 카카오톡으로 보내는 구조.

1. 이름 · 전화번호 · 고민 · 희망 일정 입력
2. "신청 메시지 만들기" → 메시지 자동 생성
3. 복사 → 카카오톡 오픈채팅 또는 인스타 DM으로 전송

| 입력 항목 | 필수 | 검증 |
|---|---|---|
| 이름 또는 닉네임 | 필수 | 빈 값 불가 |
| 전화번호 | 필수 | 휴대폰 형식(01X), 하이픈 자동 입력 |
| 가장 신경 쓰이는 것 | 선택 1개 | 기본값 "잠·휴식" |
| 희망 일정 | 필수 (복수 선택) | 1개 이상 |

생성되는 메시지 예시:

```
안녕하세요! 인스타 보고 40분 아로마 체험 신청합니다 🌿

이름: 김OO
연락처: 010-1234-5678
고민: 잠·휴식
희망 일정: 평일 저녁, 토요일
인원: 1명
```

## 8. 운영 전 체크리스트

- [ ] 카카오톡 오픈채팅이 **1:1 방**인지 확인 (그룹방이면 신청자 전화번호가 노출됨)
- [ ] 체험 조건 확인: 무료 · 롤온 증정 · 오일 6종 · 토요일 운영 · 하루 안 답장
- [ ] 롤온 사진을 센터에서 직접 찍은 사진으로 교체 (현재 외부 이미지)
- [ ] 클래스 사진의 슬라이드 문구("불면증 해소", "천연 신경안정제")가 보이지 않는 컷으로 교체 (광고 심의 리스크)
- [ ] 전화번호 수집 목적 안내 문구 추가 (예: "연락처는 체험 일정 안내에만 사용해요")
- [ ] 실제 후기 3개 + 누적 체험 인원 확보 후 후기 섹션 추가
- [ ] 수서역 출구 · 도보 시간 · 주차 정보 추가
- [ ] 휴대폰으로 신청 흐름 1회 테스트

## 10. 콘텐츠 가이드

- 의료 효능 단정 표현 금지 ("치료", "낫는다", "불면증 해소" 등)
- 체험 대상 오일은 모두 도테라 제품임을 명시
- 직함 표기는 **웰니스 리더**
- 체험은 "구매·가입 권유 없음"을 약속하고 지킬 것
